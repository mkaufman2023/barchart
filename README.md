# barchart
Reverse-engineered API for [Barchart](https://www.barchart.com/).

## Installation/Updating
- *Installation*
    ```bash
    pip install "git+https://github.com/mkaufman2023/Barchart.git@main"
    ```
- *Updating*
    ```bash
    pip install --upgrade "git+https://github.com/mkaufman2023/Barchart.git@main"
    ```
